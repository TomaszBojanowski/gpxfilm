# Test data: sources and licenses

Everything in this directory exists so that `pytest` runs without network access.
`make_test_data.py` regenerates it (see the commands at the top of that file).

| Path | What it is | Source | License |
|---|---|---|---|
| `SLAD.gpx`, `tatry.gpx`, `bez_czasu.gpx` | Made-up GPX tracks: a loop near Tre Cime di Lavaredo, a segment in the Tatra Mountains with heart rate (including a deliberate two-minute dropout written as 255 and three single 0 values), and a track to Śnieżka without times. They imitate recordings: GPS noise, one stop of a few minutes, one position jump. | Generated by `make_test_data.py gpx`. Elevations sampled from Mapterhorn terrain tiles (zoom 13). | Synthetic, part of this repository (GPL-3.0-or-later). Elevations: see Mapterhorn below. |
| `gpx/` | Small GPX variants (and a few non-GPX files) for the reader tests, imitating many exporters. | Generated by `gpx/make_variants.py` from made-up coordinates; see `gpx/README.md`. No real export is copied. | Synthetic, part of this repository (GPL-3.0-or-later). |
| `cache/osm/*.json` | Made-up Overpass API responses: named peaks, huts, passes, a viewpoint, a parking, lakes, paths, roads and places around each track. Positions are approximate. | Generated by `make_test_data.py osm`. Not downloaded from OpenStreetMap. | Synthetic, part of this repository (GPL-3.0-or-later). |
| `cache/dem/` | Terrain tiles (Terrarium-encoded WebP, 512 px) covering the test frames, zoom 12 tiles under each test track for its elevation profile, and zoom 4–11 tiles for the camera flight of the SLAD intro. The zoom 4 tiles reach from 22.5° W to 22.5° E and from 22° N to 56° N; each next zoom covers a smaller area around the track. | Mapterhorn, https://tiles.mapterhorn.com, stored exactly as served. Mapterhorn merges many elevation models; the full list of its sources, with producers and licenses, is in `mapterhorn-attribution.json`. Tiles of the far zooms combine many of these sources, so they are not listed here one by one. | The licenses of the sources, as given in `mapterhorn-attribution.json`. |
| `mapterhorn-attribution.json` | Mapterhorn's list of the elevation models behind its terrain tiles: producer, website, license and resolution of each. Copy taken on 2026-10-06. | https://download.mapterhorn.com/attribution.json, downloaded again by `make_test_data.py cache`. | Published by the Mapterhorn project, kept unchanged. |
| `cache/ne_50m_admin_0_countries.geojson` | Country borders, cut down to AT, CH, CZ, DE, IT, PL, SI, SK. | Natural Earth 1:50m Admin 0 Countries, https://github.com/nvkelso/natural-earth-vector | Public domain. |
| `cache/fonts/BigShouldersDisplay-800.ttf` | Title and numbers typeface. | Google Fonts | SIL Open Font License 1.1, `licenses/OFL-BigShouldersDisplay.txt` |
| `cache/fonts/Figtree-400.ttf`, `cache/fonts/Figtree-600.ttf` | Text typeface. | Google Fonts | SIL Open Font License 1.1, `licenses/OFL-Figtree.txt` |
| `cache/osm/` (intro peaks) | Made-up answer to the intro's question for the highest peaks around the SLAD start, including one peak outside the 20 km radius, one elevation written with a unit and one that cannot be read. Positions are approximate. | Generated by `make_test_data.py osm`. Not downloaded from OpenStreetMap. | Synthetic, part of this repository (GPL-3.0-or-later). |
| `cache/osm/` (intro places) | Made-up answer to the intro's question for the main places around the SLAD start: towns and villages with their population written in several ways, two villages without one, one village outside the 20 km radius, a city far away and a hamlet the intro does not show. Positions are approximate. | Generated by `make_test_data.py osm`. Not downloaded from OpenStreetMap. | Synthetic, part of this repository (GPL-3.0-or-later). |
| `golden/*.png`, `golden/*.json` | Reference frames and reports produced by the program from the data above; `golden/intro_*.png` are named moments of the intro and the first frame of the route. | Generated by `GPXFILM_UPDATE_GOLDEN=1 pytest tests/test_frames.py tests/test_intro.py`. | Derived from the data above. The frames of the route carry the terrain credit; the intro frames carry no credit. |
